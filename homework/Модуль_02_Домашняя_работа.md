## Цель работы

Закрепить навыки создания Web API, работы с контроллерами, маршрутизацией и HTTP-методами GET и POST.

## Задание

Создайте в Visual Studio проект ASP.NET Core Web API для управления списком книг.

### 1. Создайте модель Book

Модель должна содержать следующие свойства:

- `Id` — идентификатор книги;
- `Title` — название;
- `Author` — автор;
- `Year` — год издания.

### 2. Создайте контроллер BooksController

Используйте:

- `[ApiController]`;
- `[Route("api/[controller]")]`;
- наследование от `ControllerBase`.

### 3. Реализуйте два API-метода

- `GET /api/books` — возвращает список всех книг.
- `POST /api/books` — принимает новую книгу в формате JSON и добавляет её в список.

Для хранения данных достаточно использовать обычный `List<Book>`. Подключать базу данных не требуется.

### 4. Протестируйте API через Swagger

- выполните GET-запрос и получите список книг;
- выполните POST-запрос и добавьте новую книгу;
- повторно выполните GET и убедитесь, что книга появилась в списке.

## Что необходимо сдать

- Проект ASP.NET Core Web API.
- Скриншот Swagger с выполненным GET-запросом.
- Скриншот Swagger с выполненным POST-запросом.

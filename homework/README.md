# Домашняя работа — Модуль 02

**Тема:** Реализация веб-сервиса с применением ASP.NET Core
**Проект:** `BooksApi` (Book)

## Как запустить

```bash
cd homework
dotnet run
```

Откройте Swagger UI по адресу из вывода консоли.

## Что реализовано

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/books` | получить список всех книг |
| POST | `/api/books` | добавить новую книгу, Id генерируется автоматически |

Данные хранятся в памяти (`List<Book>` в контроллере, две заготовленные книги), без базы данных.

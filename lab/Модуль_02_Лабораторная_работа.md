## Цель работы

Получить практические навыки создания Web API на ASP.NET Core, работы с контроллерами, маршрутизацией, HTTP-методами и тестирования API с помощью Swagger.

## Задание

Разработать простой REST API для управления списком задач (Task).

### 1. Создание проекта

Создайте новый проект ASP.NET Core Web API. Убедитесь, что после запуска проекта доступен Swagger UI.

### 2. Создание модели

Создайте класс `TaskItem`:

```csharp
public class TaskItem
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Description { get; set; }
    public bool IsCompleted { get; set; }
}
```

Для хранения данных используйте `List<TaskItem>`. Использование базы данных в данной лабораторной работе не требуется.

### 3. Создание контроллера

Создайте контроллер `TasksController` с атрибутами `[ApiController]`, `[Route("api/[controller]")]`, наследованием от `ControllerBase`.

### 4. Реализация REST API

| HTTP | Маршрут | Назначение |
|---|---|---|
| GET | `/api/tasks` | Получить все задачи |
| GET | `/api/tasks/{id}` | Получить задачу по ID |
| POST | `/api/tasks` | Добавить новую задачу |
| PUT | `/api/tasks/{id}` | Изменить существующую задачу |
| DELETE | `/api/tasks/{id}` | Удалить задачу |

### 5. HTTP-коды ответа

- `200 OK` — запрос успешно выполнен;
- `201 Created` — создан новый объект;
- `400 Bad Request` — переданы некорректные данные;
- `404 Not Found` — объект не найден.

### 6. Тестирование через Swagger

Запустите приложение и протестируйте API через Swagger UI:

1. POST — создайте минимум 3 задачи.
2. GET — получите список всех задач.
3. GET /{id} — получите одну задачу.
4. PUT /{id} — измените название или статус задачи.
5. DELETE /{id} — удалите одну задачу.
6. Повторите GET и убедитесь, что изменения применились.

## Результат работы

В результате лабораторной работы должен работать REST API, позволяющий создавать → получать → изменять → удалять задачи.

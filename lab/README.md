# Лабораторная работа — Модуль 02

**Тема:** Реализация веб-сервиса с применением ASP.NET Core
**Проект:** `TasksApi` (TaskItem)

## Как запустить

```bash
cd lab
dotnet run
```

Откройте Swagger UI по адресу из вывода консоли.

## Что реализовано

| Метод | Endpoint | Назначение | Успешный код | Код ошибки |
|---|---|---|---|---|
| GET | `/api/tasks` | получить список всех задач | 200 OK | — |
| GET | `/api/tasks/{id}` | получить задачу по Id | 200 OK | 404 Not Found |
| POST | `/api/tasks` | добавить новую задачу | 201 Created | 400 Bad Request (пустой `Title`) |
| PUT | `/api/tasks/{id}` | изменить задачу | 200 OK | 404 Not Found / 400 Bad Request |
| DELETE | `/api/tasks/{id}` | удалить задачу | 200 OK | 404 Not Found |

Данные хранятся в памяти (`List<TaskItem>` в контроллере, две заготовленные задачи), без базы данных. Id новой задачи генерируется автоматически (`Max(Id) + 1`).

## Контрольные вопросы

1. **Что такое Web API?** — программный интерфейс, через который приложения обмениваются данными по HTTP, обычно в формате JSON, без графического интерфейса.
2. **Для чего используется атрибут `[ApiController]`?** — включает поведение, специфичное для Web API: автоматическую валидацию модели с ответом 400 при ошибке, автоматическое связывание параметров из тела/маршрута/строки запроса, единообразную обработку ошибок.
3. **Для чего используется `[Route]`?** — задаёт шаблон URL, по которому контроллер (или отдельное действие) будет доступен; `[controller]` подставляет имя класса без суффикса `Controller`.
4. **Чем отличаются методы GET и POST?** — GET читает данные и не изменяет состояние сервера, безопасен и идемпотентен; POST создаёт новый ресурс и меняет состояние, не идемпотентен.
5. **Чем отличаются PUT и DELETE?** — PUT обновляет/заменяет существующий ресурс по Id; DELETE удаляет ресурс по Id. Оба идемпотентны: повторный вызов с теми же параметрами даёт тот же результат.
6. **Что означают HTTP-коды 200, 201, 400 и 404?** — 200 — запрос выполнен успешно; 201 — создан новый ресурс (ответ на POST); 400 — в запросе переданы некорректные данные; 404 — запрошенный ресурс не найден.

## Цель работы

Научиться создавать проект ASP.NET Core Web API, работать с контроллерами, маршрутизацией и HTTP-методами GET и POST, а также тестировать API через Swagger.

## Задание

Разработать простой Web API для хранения информации о студентах.

### 1. Создание проекта

Создайте новый проект ASP.NET Core Web API. Запустите проект и убедитесь, что открывается Swagger UI.

### 2. Создание модели

```csharp
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Group { get; set; }
}
```

### 3. Создание контроллера

```csharp
[ApiController]
[Route("api/[controller]")]
public class StudentsController : ControllerBase
{
    // Методы API
}
```

Контроллер должен наследоваться от `ControllerBase`, содержать атрибут `[ApiController]`, использовать маршрут `[Route("api/[controller]")]`.

### 4. Добавление тестовых данных

```csharp
private static List<Student> students = new()
{
    new Student { Id = 1, Name = "Alex", Group = "SE-301" },
    new Student { Id = 2, Name = "Anna", Group = "SE-302" },
    new Student { Id = 3, Name = "Max", Group = "SE-301" }
};
```

### 5. Реализация GET

`GET /api/students` — возвращает список всех студентов в формате JSON.

### 6. Реализация GET по ID

`GET /api/students/{id}` — возвращает информацию только об одном студенте. Если студент с указанным Id отсутствует — `404 Not Found`.

### 7. Реализация POST

`POST /api/students` — принимает нового студента в формате JSON и добавляет его в список. Пример запроса:

```json
{
  "id": 4,
  "name": "John",
  "group": "SE-303"
}
```

После добавления студента выполните `GET /api/students` и убедитесь, что новый студент появился в списке.

## Проверка через Swagger

1. Получите список всех студентов — GET.
2. Получите студента по Id — GET /{id}.
3. Попробуйте запросить несуществующий Id и получите 404.
4. Добавьте нового студента — POST.
5. Снова получите список студентов и проверьте результат.

## Что необходимо показать преподавателю

- запущенный проект;
- Swagger UI;
- работающий GET /api/students;
- работающий GET /api/students/{id};
- работающий POST /api/students;
- корректный ответ 404 Not Found.

# Практическая работа — Модуль 02

**Тема:** Реализация веб-сервиса с применением ASP.NET Core
**Проект:** `StudentsApiM2` (Student)

## Как запустить

```bash
cd prac
dotnet run
```

Откройте Swagger UI по адресу из вывода консоли.

## Что реализовано

| Метод | Endpoint | Назначение | Успешный код | Код ошибки |
|---|---|---|---|---|
| GET | `/api/students` | получить список всех студентов | 200 OK | — |
| GET | `/api/students/{id}` | получить студента по Id | 200 OK | 404 Not Found |
| POST | `/api/students` | добавить студента | 200 OK | — |

Данные хранятся в памяти (`List<Student>`, три заготовленных студента). Id нового студента методичка требует передавать явно в теле запроса (пример — `{"id": 4, ...}`), поэтому автогенерации Id здесь нет, в отличие от домашней и лабораторной работ этого модуля.

## Контрольные вопросы

1. **Что такое Web API?** — программный интерфейс для обмена данными между приложениями по HTTP, обычно в формате JSON, без графического интерфейса.
2. **Для чего нужен `ControllerBase`?** — базовый класс для Web API-контроллеров (без Views); предоставляет методы `Ok()`, `NotFound()` и другие для формирования HTTP-ответов.
3. **Что делает атрибут `[ApiController]`?** — включает автоматическую валидацию модели, привязку параметров и единообразную обработку ошибок для контроллера.
4. **Для чего используется `[Route]`?** — задаёт шаблон URL-маршрута, по которому доступен контроллер или конкретное действие.
5. **В чём разница между GET и POST?** — GET читает данные без изменения состояния сервера; POST создаёт новый ресурс и меняет состояние.
6. **Что означает HTTP-код 404 Not Found?** — запрошенный ресурс с указанным идентификатором не найден.
